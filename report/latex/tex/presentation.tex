\begin{itemize}
	\setlength{\itemsep}{11pt}
	\item \textcolor{Crimson}{\textbf{Algorithmic Bias \& False Positives:}} I\textit{mbalanced datasets risk generating biased rules that unfairly target specific demographic spending behaviors as anomalous.}
	\item \textcolor{ForestGreen}{\textbf{Human-in-the-Loop Accountability:}} \textit{By incorporating mandatory human escalation for low-confidence decisions, the system prevents autonomous wrongful account blocking and ensures user due process.}
	\item \textcolor{RoyalBlue}{\textbf{Data Privacy:}} \textit{Synthetic data generation (CTGAN) helps mitigate privacy leakage by supplementing training pipelines without over-relying on sensitive real-world cardholder records.}
\end{itemize}

\begin{frame}
	\frametitle{6. Evaluation, Limitations, and Risks (Cont. D)}
\begin{itemize}
	\setlength{\itemsep}{11pt}
	\item \textcolor{ForestGreen}{\textbf{Successes:}} Dual thresholds successfully filtered unambiguous traffic. LLM+LTM improved sequential accuracy,  and human only involved when necessary.
	\item \textcolor{RoyalBlue}{\textbf{Limitations:}} Asymmetric precision/recall behavior (cause by Prompt)  we need to decouple agent-specific precision and recall metrics during optimization.
	\item  \textcolor{Crimson}{\textbf{Potential Metric Inflation}}: Using same data in both step-1, and step-2 was necessary for initial feasibility, it can introduces \textit{data leakage}, potentially leading to optimistic metrics.  Let say, we have 5\% performance inflation, then the realistic F2-Score is  92.2\%. 
\end{itemize}
\end{frame}
